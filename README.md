# Jubair Ahmad Warisi | Portfolio

One-page portfolio website of **Jubair Ahmad Warisi**, Founding Principal and Islamic education leader.

## Files

```
index.html                       the website (all CSS and JS inside)
assets/photo.jpg                 profile photo
assets/Jubair-Ahmad-Warisi-CV.pdf  downloadable CV
META-PROMPT.md                   the design brief the site was built from
```

## Publish on GitHub Pages (free)

1. Sign in at https://github.com and click **New repository**.
2. Name the repository `your-username.github.io` (use your real GitHub username). Set it to **Public** and click **Create repository**.
3. Click **uploading an existing file**, then drag in `index.html`, `README.md`, `META-PROMPT.md` and the whole `assets` folder. Click **Commit changes**.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
5. After 1–2 minutes the site is live at `https://your-username.github.io`.

## After publishing

Open `index.html` and replace `your-username` with your GitHub username in the canonical, Open Graph, Twitter and JSON-LD image URLs (search for `your-username`). This makes link previews on WhatsApp, Facebook and LinkedIn show your photo.

## Updating

- **New CV:** replace `assets/Jubair-Ahmad-Warisi-CV.pdf` with a file of the same name.
- **New photo:** replace `assets/photo.jpg`.
- **Text:** edit `index.html` directly on GitHub (pencil icon) and commit.
